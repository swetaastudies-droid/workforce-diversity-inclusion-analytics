# 📊 Workforce Diversity & Inclusion Analytics Dashboard

> An HR Analytics project designed to analyze workforce diversity, inclusion, pay equity, promotion patterns, training participation, and employee retention using Microsoft Excel and Power BI.

---

## 📌 Project Overview

The **Workforce Diversity & Inclusion Analytics Dashboard** transforms workforce data into meaningful HR insights related to representation, inclusion, compensation, career progression, training, and retention.

The project combines **Microsoft Excel** for data preparation, KPI calculations, diversity scoring, and scenario analysis with **Microsoft Power BI** for interactive dashboard development and visualization.

The analysis uses **200 synthetic/anonymized employee records** created for educational and analytical purposes.

---

## 🎯 Project Objectives

The project aims to:

- Analyze workforce demographic representation
- Examine gender, age, and ethnicity distribution
- Analyze promotion patterns across demographic groups
- Evaluate pay equity indicators
- Measure training participation
- Analyze employee exit patterns
- Develop a Diversity Index and scorecard
- Simulate workforce interventions using Scenario Manager
- Build an interactive Power BI dashboard
- Convert analytical findings into HR recommendations
